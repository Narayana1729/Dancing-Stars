# Processed Working Boundary Layers (EPSG:32645)

This directory contains standardized, topologically verified GIS working layers reprojected to `EPSG:32645` (WGS 84 / UTM Zone 45N) to match the NISAR L2 GCOV coordinate reference system.

## Files

1. `similipal_core_epsg32645.geojson`
   - **Feature:** Similipal Core Area (Critical Tiger Habitat, WDPA Site ID `556167801`).
   - **Legal Status:** Statutory Inviolable Core Reserve (Notification No. 8F(T)-13/2007-20807/F&E, 31-Dec-2007).
   - **Planar Area:** 1,224.30 km² (matches gazetted 1,194.75 km² within 2.47%).
   - **Observed by Track 098 Swath:** 222.00 km² (18.29%).

2. `similipal_sanctuary_epsg32645.geojson`
   - **Feature:** Unified Similipal Wildlife Sanctuary Complex (dissolved union of all 11 constituent ranges).
   - **Legal Status:** Wildlife Sanctuary (Notified 03-Dec-1979 under Section 18).
   - **Planar Area:** 2,178.22 km² (matches gazetted 2,200.00 km² within 0.99%).
   - **Observed by Track 098 Swath:** 281.72 km² (13.54%).

3. `similipal_ranges_epsg32645.geojson`
   - **Feature:** FeatureCollection containing 11 constituent legal polygon parcels representing the 8 internal wildlife ranges (Barehipani, Chahala, Gurguria, Kendumundi, Nawana North, Talabandha, Thakurmunda) and the central Core parcel.
